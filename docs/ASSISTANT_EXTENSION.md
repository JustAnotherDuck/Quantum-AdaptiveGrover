# Natural Language Research Assistant Extension

The AdaptiveGrover-QCA research platform includes a domain-grounded conversational assistant that bridges natural language queries to rigorous quantum cryptanalysis simulations, literature evidence, and cryptographic readiness assessments.

---

+------------------------------------+-------------------------------------+

---

## 2. Safety Rules & Verification Guardrails

1. **Absolute Anti-Hype Guardrail**: Under no circumstance will the assistant assert or imply that quantum computers can break production AES-128 or AES-256 today. Any query touching AES security is grounded in peer-reviewed resource estimates showing that unmitigated NISQ circuit survival probability is mathematically zero ($0.00 \times 10^0$).
2. **Fair Filtering Guardrail**: When users ask about candidate filtering or key constraints, the assistant explains that search space pruning ($N \to N'$) is a classical effect ($N/N'$), and reports quantum-specific speedup ($S_{\text{quantum}}$) separately from the classical reduction factor.
3. **Mandatory Confirmation**: To prevent inadvertent long-running simulations, the assistant parses user intents into a structured `SimulateRequest` and requires explicit confirmation before triggering execution.
4. **Deterministic Offline Fallback**: If `ANTHROPIC_API_KEY` is absent or the network is inaccessible, the assistant falls back to a deterministic scientific reasoning engine that handles queries regarding crossover boundaries, noise thresholds, scaling exponents, and readiness verdicts.

---

## 3. Mandatory Scientific Disclaimer

Every response generated by the assistant contains the standard disclaimer:
> *"Scientific Caveat: Experimental estimates produced on educational ciphers and simulation models; not a formal cryptographic certification. No claim is made that current hardware can break AES-128 or AES-256."*
